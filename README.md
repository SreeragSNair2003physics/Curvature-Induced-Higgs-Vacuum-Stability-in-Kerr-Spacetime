# Curvature-Induced Higgs Vacuum Stability in Kerr Spacetime

## About This Project

This is a self-directed computational physics project exploring how spacetime curvature around a rotating black hole might influence a Higgs-like scalar field.

## Goals

- Learn the physics of rotating black holes.
- Calculate spacetime curvature using Python.
- Explore mathematical models of scalar-field potentials.
- Develop reliable, reproducible scientific code.

## Tools

- Python
- NumPy
- Matplotlib
- Git and GitHub

## Project Status

**Stage:** Initial setup and learning.

The physical model and numerical methods are still being developed. No conclusions about the stability of the Standard Model Higgs vacuum have been established.

## Author's Note

This project is being developed step by step, with an emphasis on understanding the underlying physics, checking numerical results, and documenting assumptions and limitations.
